# Lucide 图标搜索与接入

## 搜索与选型

1. 先检查目标界面已有图标及封装，沿用相同动作的图标语义。将需求转换为英文动作或对象关键词，例如“历史记录”可搜索 `history`、`clock`；无合适结果时扩展同义词或所属分类。
2. 在 [Lucide 官方图标目录](https://lucide.dev/icons/) 搜索并预览候选，比较语义、轮廓和小尺寸辨识度。搜索工具可使用 `site:lucide.dev/icons/ <关键词>`，再打开具体图标页面核实名称与外观。
3. 官网搜索不可用或需要核对源码时，查阅 [Lucide GitHub 仓库](https://github.com/lucide-icons/lucide) 的 `icons/` 目录，按文件名及相关元数据查找 SVG。无法访问官方资料时说明限制，优先使用已安装包中可核实的图标。
4. 交付推荐图标的准确名称、具体官方页面链接和适用理由；语义有歧义时给出少量备选并说明区别。品牌标识使用项目已有品牌资源，Lucide 不提供品牌 Logo。

## 接入与验证

- 实现前读取项目已有的 UI 规范与设计令牌文档，核对现有图标封装、`components.json`（如有）、`package.json` 与锁文件。官网可能比本地版本更新，使用前确认所选图标在已安装版本中的真实导出名；优先选择当前版本可用的等价图标。
- 按目标框架选择 Lucide 官方集成；React 项目用法以 [Lucide React 官方文档](https://lucide.dev/guide/react) 和本地版本为准。复用现有 `lucide-react` 依赖，按名称静态导入所需图标；仅在实际实现且缺少依赖时，沿用项目包管理器添加。单纯搜索无需安装依赖。
- 沿用项目图标尺寸、描边和语义颜色，优先通过 `currentColor` 与已有样式保持一致。图标按钮提供表达动作的可访问名称，装饰图标从可访问树隐藏。
- 按主流程完成类型检查与受影响 UI 状态验证，确认导出可用、小尺寸清晰、对齐正确、按钮点击区域与键盘焦点可用。

# Codex 默认配置与 Top 5

本规范仅在当前运行环境标识为 `codex`（大小写不敏感）时查阅执行。

## 数据获取

在展示 subagent 模型与思考强度配置表时，先读取 [Codex 雷达](https://codex-reset-radar.pages.dev/) 的 `https://codex-reset-radar.pages.dev/data/intelligence-efficiency.json`。

读取顺序：
1. 优先使用当前可用的网页工具读取完整 JSON URL。
2. 网页工具不可用或受限时，改用当前环境允许的只读 HTTPS 客户端（如 `curl` 或 `Invoke-WebRequest`）获取。
3. 成功获取后，从顶层 `points` 读取模型档位。模型名使用 `model`，推理强度使用 `effort`。
4. 获取失败、结构无法解析或筛选后无候选时，说明原因，按计划复杂度从 runtime 可用配置中生成默认角色表，价格标为「暂无数据」，Top 5 标为「暂无可用排名」。

## 候选筛选与推荐计算

- 所有 Codex 推荐均排除 `effort == "ultra"`（大小写不敏感），包括数据获取失败时的默认角色建议。
- 候选条件：`harness == "codex"`，`model` 与 `effort` 均非空，`iq` 为有限非负数，`average_price_usd` 为有限正数。
- 以当前 runtime 的 subagent 工具支持的模型与推理强度组合筛选候选。计划已限定模型族时进一步按计划筛选。
- 默认角色表与 Top 5 使用同一基础候选集，每个「模型 + 强度」组合算一个档位。Top 5 进一步应用下述 IQ 门槛。
- **执行者推荐**：IQ ≥ 95 中价格最低的档位。
- **任务审查者推荐**：IQ ≥ 100 中价格最低的档位。
- **最终整体审查**：IQ 最高的档位。
- 门槛无候选时，该角色取 IQ 最高的档位（三个角色可共用同一档位）。
- 按价格选取时，同价优先 IQ 更高；按 IQ 选取时，同分优先价格更低。仍相同时按模型名、强度的字典序选取。
- 价格使用 `average_price_usd`（美元/基准任务）；日期使用 `source_updated_at`（北京时间日期）。

## Top 5 计算

- 将基础候选集的 IQ 升序排列，移除首尾各一个观测值，用剩余数据计算第 60 百分位数 `P60`。并列极值也各移除一个观测值。基础候选不足 3 个时展示「候选不足，无法计算去头去尾 P60」。
- 将剩余 IQ 记为 `x[0..n-1]`，取 `h = 0.6 * (n - 1)`，在 `x[floor(h)]` 与 `x[ceil(h)]` 之间按 `h` 的小数部分线性插值。
- 从完整基础候选集中筛选 **IQ > P60** 的档位入榜。去头去尾仅用于计算门槛。合格候选不足 5 个时展示实际数量；无合格候选时展示「暂无 IQ 高于去头去尾 P60 的档位」。
- 在合格候选中分别取 IQ 与价格的最小值、最大值，计算归一化分数：`iq_score = (iq - iq_min) / (iq_max - iq_min)`，`price_score = (price_max - average_price_usd) / (price_max - price_min)`。某项最大值等于最小值时，该项统一记为 1。
- 综合分数为 `0.8 * iq_score + 0.2 * price_score`，按分数降序取前 5 个档位。IQ 权重为 **80%**，价格权重为 **20%**。
- 同分时依次按 IQ 降序、价格升序、模型名和强度字典序排序。使用原始精度计算，展示时再舍入。
- 同一模型的不同强度可分别入榜。

## 输出格式

先展示默认 subagent 配置表，用实时计算结果填入各角色：

| 角色 | 模型 | 推理强度 | 价格（美元/基准任务） |
|------|------|----------|---------------------|
| 执行者 | <model> | <effort> | $<average_price_usd> |
| 任务审查者 | <model> | <effort> | $<average_price_usd> |
| 最终整体审查 | <model> | <effort> | $<average_price_usd> |

随后展示「综合 IQ 与价格的 Top 5」，注明「IQ > 去头去尾 P60（本次值：<P60>）；归一化评分：IQ 80% + 价格 20%；按综合分降序」，表格按排名排列：

| 模型名 | 强度 | IQ | 价格（美元/基准任务） |
|--------|------|----|---------------------|
| <model> | <effort> | <iq> | $<average_price_usd> |

表下标注数据来源为 [Codex 雷达](https://codex-reset-radar.pages.dev/)，并展示更新时间。缺少 `source_updated_at` 时标为「更新时间未知」。

用户已指定的角色配置优先保留，其价格按相同模型与强度匹配；缺少匹配数据时标为「暂无数据」。两张表展示完毕后，请用户确认或调整角色配置。将确认后的配置写入账本供后续派发使用。

# 头脑风暴场景模式深入指引

五步是主干，每次都走。模式决定各步的配重。看清楚用户处在哪种处境，按对应小节深入推进。

## 问题探索

**适用处境**：有个问题域，但还没想清要解决什么（重心：定框 + 发散）。

- 先问「谁有这个问题」和「他们现在怎么凑合的」，别的都往后放。
- 分清**症状和病根**：用户描述的往往是症状，一直追问「为什么」直到碰到结构性的东西。
- 考察在不同用户群上的差异：问题很少对所有人一样。
- **好问题**：
  - 「什么都不做会怎样，谁难受、怎么难受？」
  - 「谁在别的场景下解过这个问题的变体？」
  - 「这是不知道、不会用，还是不想用？」

## 方案生成

**适用处境**：问题清楚了，需要更多解法（重心：发散）。

- 详见主干「2. 发散」。
- 卡住时查阅 [frameworks.md](frameworks.md) 中的反演、第一性原理、HMW、SCAMPER 等工具。

## 假设检验

**适用处境**：已经有方向，想知道它扛不扛得住（重心：逼问）。

- 详见主干「3. 逼问」。
- 锁定最贵的那条致命假设，设计低成本证伪动作。

## 战略探索

**适用处境**：在想方向、定位、大的押注（重心：定框 + 逼问）。

- **把棋盘摊开**：寻找有哪些可能的走法，不局限于显而易见的那步。
- **用下注的语言**：赌的是什么、赔率多少、赢了拿多少。
- **想二阶效应**：「做了 X，它打开了什么、又关上了什么？」把竞争对手与生态的反应算进去。
- **分时间尺度**：3 个月、12 个月、3 年，最优解不是同一个。

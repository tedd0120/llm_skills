# Emoji 格式化规范（Moderate 风格）

本文件供 `xiaohongshu-formatter` 执行报告美化时查阅。

## 风格原则

适度使用、语义相关、保持数据分析报告的专业感。具体 emoji 由 Agent 根据上下文选取。

## 必须使用 Emoji 的位置

| 位置 | 示例 | 说明 |
|:-----|:-----------|:-----|
| 报告标题 | ☕️ 北京咖啡厅探店报告 ☕️ | 前后各一个 |
| 主要板块标题 | 📊 搜索概览、🔥 声量分析、💬 高频共识、📍 数据来源说明 | 标题前加一个 |
| 场景推荐表格 | ☕ Dirty首选、📚 自习办公 | 场景列加 emoji |
| 避雷问题类型 | 🚫 空间问题、💸 价格问题 | 问题分类标识 |
| 优缺点列表前缀 | ✨ 核心优点、😤 核心痛点 | 列表标题 |
| 关键洞察编号后 | 1. ☕ Dirty是... | 每条洞察一个 |
| 表格内的评级 | ⭐⭐⭐⭐⭐ | 质量评分 |
| 热度指示 | 🔥🔥🔥 | 3-5个火焰表示热度 |

## 不使用 Emoji 的位置

- 引用的用户评论内容（保持原始感）
- 来源标注行
- 长段落正文
- 价格档位（保持清晰简洁）

## 搜索路径板块美化规则（多轮模式）

当报告中存在「搜索发散路径」或「搜索总分路径」表格时：
- 仅优化表格样式与可读性，严禁改动原始关键词或理由的核心文本含义；
- 保持列结构不变（发散路径为 `轮次 | 关键词 | 实际篇数 | 发散理由`；总分路径为 `轮次 | 关键词 | 实际篇数 | 说明`）；
- 关键词列可按语义补充前缀 emoji；理由/说明列可用轻量 emoji（如 💡、🔁、🎯）；
- `合计` 行保持简洁，不堆叠 emoji。

## 格式化示例

```markdown
# 北京咖啡厅探店报告
## 搜索概览

↓ 格式化后

# ☕️ 北京咖啡厅探店报告 ☕️
## 📊 搜索概览
```

*注：数据来源说明板块仅在标题前加 📍，免责声明文本、生成时间、工具版本原样保留，禁止改写。*

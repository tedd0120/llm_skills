# 媒体事实信息网络核实规则（强制）

为防止乱猜导致刮削失败，凡是涉及“事实信息”的字段，在写入方案前必须通过网络核实，严禁凭直觉或目录名臆测。

## 必须核实的事实字段

- 作品正式官方名称（中/英文）；
- 首播 / 上映年份；
- 作品类型归类（电影 / 剧集 / 综艺 / 纪录片）；
- 季数与总集数（或总期数）。

## 权威数据来源优先级

通过网络搜索优先采用以下权威数据源（按置信度排序）：

1. **TMDB（themoviedb.org）**：首选权威，命名与季集划分与 Emby/Jellyfin 完全对齐；
2. **IMDb（imdb.com）**：欧美电影与剧集权威；
3. **豆瓣（movie.douban.com）**：中文译名与国内综艺期数参考；
4. **维基百科 / 百度百科**：综艺分季与特别篇佐证。

## 检索与判定要点

- **年份口径**：剧集与综艺取**该季首播年**（非整部剧初播年）；电影取上映年。目录名年份常见完结年等错误，必须以核验事实为准。
- **期数映射**：核实该季总期数连续无缺漏后，再映射为 `SxxEyy`。
- **何时必须主动询问用户**：
  - 网络检索无任何权威收录（属于小众或私人录播）；
  - 存在多部同名作品且无法根据年份/主演排除；
  - 综艺跨年特别篇或衍生短片的季划分存疑。
  此时必须向用户逐条确认，严禁自行脑补。

## 负向红线

- 严禁仅凭目录名或文件名推断年份与季集；
- 严禁把别名或非正式翻译作为正式作品名；
- 严禁跳过检索直接输出未验证的推测方案。

# 360Teams 代理检测与修复

## 入口与完成条件

用户要求检测或修复时，从只读检测开始。用户明确要求撤销本补丁时，进入还原流程。
用户调用本 skill 修复故障时，授权包含有证据支持的补丁应用和必要的客户端重启。
仅咨询原理或只读检查时，报告发现与具体修复方案。

修复完成必须同时有：客户端正常启动、待办内网提示消失、目标请求进入预期代理端口并经过公司 VPN 节点。
记录未验证项目。探测请求返回 200 本身只证明代理链路可用。

## 检测

1. 从运行进程或安装信息确定 `360 Teams.exe` 的路径。查看系统代理、客户端网络模式及进程启动时间。
2. 执行 `python scripts/diagnose.py --output-dir <可选报告目录>`。脚本输出报告路径，读取 JSON 中的证据。
3. 在客户端的待办页复现，关注 `https://sk.360teams.com/nsf.gif`。先验证当前版本仍使用这个地址。网页调试可能在主窗口或独立 WebView；只读取相关请求的地址、错误与状态，避免输出聊天内容、Cookie 和认证头。
4. 点击重新加载，同时检查 Clash 的连接记录。关联目标域名、360Teams 进程、代理入口和公司节点链路。按实际配置读取 HTTP/mixed 端口；历史值 `7897` 仅作线索。

证据分支：

| 观察 | 动作 |
|---|---|
| 目标请求走公司节点且待办正常 | 报告正常，结束 |
| 请求进入 Clash，但匹配 DIRECT 或其他节点 | 定位分流规则，按用户任务范围修复并复验 |
| 经本地代理的检测请求也失败 | 排查代理监听、虚拟机 VPN、DNS 和目标可达性 |
| 经代理成功，客户端同一请求直连失败 | 检查客户端代理生效逻辑，进入补丁流程 |
| 缺少目标请求的连接证据 | 继续采集；不要把空连接快照当成绕过代理的结论 |

部分 IM 连接可合法直连。`HTTP_PROXY` 环境变量与 Windows 系统代理是不同配置来源。

## 补丁

先读取 [补丁适配与限制](references.md)。当前脚本仅支持已验证的混淆代码构建，通过精确语句及原文件哈希校验匹配。版本号相同不保证适配。

1. 在客户端选择“系统默认”。先正常退出再启动一次，复验是否已恢复。
2. 若仍失败，核实包内的 `no-proxy-server` 启动逻辑及后续 `auto` 会话策略。
3. 准备补丁：

   ```powershell
   python scripts/patch.py prepare --target 'S:\360 Teams\resources\app.asar'
   ```

   使用现场发现的路径。准备过程备份原包，校验修改文件的 JS 语法、ASAR 元数据、其他文件内容与应用完整性清单。它输出持久状态目录。
4. 正常退出客户端（Ctrl+Q）。确认进程退出后执行 `apply`，参数与准备时相同。脚本遇到运行进程或不同版本会停止。
5. 正常启动客户端并完成三项验收。用 Clash 连接记录核对 `sk.360teams.com` 和审批页面实际域名经过公司节点。对界面只确认加载状态和内网提示，不操作审批业务。
6. 报告补丁状态、验证结果和持久备份位置。客户端升级后重新检测并判断构建适配情况。

成功安装的补丁持续保留。若本次安装造成启动失败或引入明确回归，立即用本次备份恢复可启动状态并报告原因；这属于失败安装回滚。

## 用户主动还原

用户明确提出“还原／撤销补丁／恢复原版”后执行：

1. 运行 `status`，核实目标包与状态清单中的补丁哈希一致。
2. 正常退出客户端，执行 `restore`，再正常启动。
3. 核实目标 SHA-256 与原始备份相同，确认客户端可启动。还原可能恢复原先的代理问题，按实测报告。

三个命令共享参数：

```powershell
python scripts/patch.py status --target '<实际 app.asar 路径>'
python scripts/patch.py apply --target '<实际 app.asar 路径>'
python scripts/patch.py restore --target '<实际 app.asar 路径>'
```

若用户升级过客户端，停止覆盖并说明版本不匹配。保留备份供核查。

## 文件位置

脚本的 `--output-dir` 和 `--state-dir` 优先指定目录。随后依次解析对应的 `LLM_SKILLS_DATA_DIR` / `LLM_SKILLS_STATE_DIR`、脚本所属 Git 仓库、用户级 `.llm-skills` 目录。
补丁状态按目标绝对路径分目录。保留原包、候选包和 manifest，后续还原使用同一状态目录。
检测报告写入 `data/360teams-proxy-repair/`。备份写入 `.local/360teams-proxy-repair/`，程序包不放入 skill 源码目录。

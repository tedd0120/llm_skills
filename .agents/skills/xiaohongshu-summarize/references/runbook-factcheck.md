# 事实/风险判断报告 Runbook

回答「这件事到底是什么情况」。适用于真假判断、概率估计、风险与可靠性评估。

在搜索概览（及可选发散路径）后依次输出：

1. `## 结论与置信度`：置顶给出 `支持/不支持/证据不足` 结论、置信度和一句话理由。
2. `## 支持证据`：列出支持侧独立内容组数、证据等级、适用时间与代表来源。
3. `## 反对证据`：使用与支持侧相同口径，不得省略不利证据。
4. `## 样本局限`：说明采集覆盖、平台偏差、时间窗口和无法验证的变量。
5. `## 结论适用边界`：明确结论对哪些人群、地域、时段或条件成立，何时需要重新判断。
6. 按 common 输出 `## 数据来源说明`。

禁止只列单侧证据；支持与反对两侧必须并列给出独立内容组数。若关键事实无法由用户内容验证，明确写「小红书样本不能证明」，不要把舆论声量当作事实概率。

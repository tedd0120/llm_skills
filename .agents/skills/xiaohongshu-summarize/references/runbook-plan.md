# 方案/行程规划报告 Runbook

回答「我该按什么顺序做什么」。适用于行程、攻略、执行方案和清单。

在搜索概览（及可选发散路径）后依次输出：

1. `## 方案结论`：置顶给出可直接执行的总路线、顺序和关键取舍。
2. `## 分阶段明细`：按天、阶段或步骤列出动作、地点/对象、预计时间和完成条件。
3. `## 成本与时间预算`：给出分项预算、总量、计算口径及价格时效提示。
4. `## 常见翻车点`：说明触发条件、影响和规避动作，不堆砌泛化提醒。
5. `## 备选路线`：仅为最可能发生的变更提供替代路径，并写明切换条件。
6. 按 common 输出 `## 数据来源说明`。

硬约束：

- `方案结论` 必须是搜索概览和可选发散路径后的第一个决策板块。
- 证据不足以排出顺序时，明确写「现有样本不足以形成可靠方案」，列出缺失信息和补充搜索词；不得编造确定性。
- 每个阶段必须收敛到可执行动作，不使用「可考虑 A/B/C」式无结论罗列。
- 不生成商品式首选、品牌声量或避雷型号板块。

# 议题探索报告 Runbook

回答「这个话题的讨论全貌是什么」。作为不匹配其他类型时的兜底。

在搜索概览（及可选发散路径）后依次输出：

1. `## 议题地图`：列出主要子议题、讨论对象与证据组数。
2. `## 主要观点阵营`：分别说明各阵营主张、适用人群、证据等级与代表来源。
3. `## 高频共识`：只收录跨多个独立内容组出现的共识。
4. `## 主要分歧`：对照冲突观点，解释分歧来自人群、场景、时间还是信息缺口。
5. `## 关键洞察`：给出有来源支撑的归纳，并区分事实与推断。
6. 按 common 输出 `## 数据来源说明`。

禁止生成首选短名单、成本比较或避雷板块。若用户实际在候选集中做选择，应改用 `recommend`。

# 模式 A（固定关键词）：分支专属轮次

本文件定义模式 A 在澄清阶段的专属交互轮次。每次输出仅包含一个问题，等待用户回复后再继续。

## 关键词衍生与确认轮

用户回复篇数上限后，根据篇数上限衍生 2-4 个搜索关键词并向用户展示：

```markdown
我基于你的建议衍生了以下 3 个搜索词：

| 序号 | 关键词 | 预计篇数 | 搜索理由 |
|:----:|:------|:--------:|:---------|
| 1 | [关键词一] | 10篇 | [理由一] |
| 2 | [关键词二] | 10篇 | [理由二] |
| 3 | [关键词三] | 10篇 | [理由三] |
| **总计** | — | **30篇** | — |

报告形态：[推断的中文名]（`REPORT_TYPE`）

你可以：修改单个关键词、调整数量、重新生成、覆盖报告形态、或确认开始爬取。
```

等待用户回复，循环调整直到用户明确确认（如回复“确认”、“开始”、“好的”、“就这样”等），再进入速度模式轮。

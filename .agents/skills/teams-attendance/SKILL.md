# Teams 考勤数据 Skill

从360teams平台获取员工考勤数据，计算有效工作日和平均工时，并按标准模板回复。

---

## 前置配置

在项目根目录 `.env` 文件中配置：

```env
TEAMS_EM_CODE=你的员工编码
TEAMS_AUTHORIZATION=你的授权令牌
```

## 功能

1. **考勤数据获取** - 从360teams API获取指定月份考勤明细
2. **工时统计** - 自动计算已工作天数、已累计工时、当前平均工时、剩余工作日
3. **达标预测** - 基于目标工时（10.5/10.7/11小时）计算剩余工作日每日所需工时
4. **CSV导出** - 自动保存考勤明细到CSV文件（默认 `data/attendance_YYYYMM.csv`）

## 使用方法

```bash
# 查询当前月份
python .claude/skills/teams-attendance/scripts/fetch_attendance.py

# 查询指定月份
python .claude/skills/teams-attendance/scripts/fetch_attendance.py --month 2026-01

# 导出CSV到指定路径
python .claude/skills/teams-attendance/scripts/fetch_attendance.py --month 2026-01 --output ./data/attendance_202601.csv
```

## 参数说明

| 参数 | 类型 | 说明 |
|-----|------|-----|
| check_month | str | 查询月份，格式 YYYY-MM；不传则查询当前月份 |
| output_path | str | CSV输出路径，默认 `data/attendance_YYYYMM.csv` |

## 执行步骤

**[核心要求]** 调用此 Skill 时，按以下顺序执行：

1. 运行脚本获取实时数据：`python .claude/skills/teams-attendance/scripts/fetch_attendance.py`
2. 解析脚本终端输出，提取统计数值和明细列表
3. 按 Agent 回复模板格式化并发送回复

|:-----|-----:|

## 明细展示规则

**[核心要求]** 明细表格须满足以下规则：

1. **仅展示工作日**：过滤掉 `假期flag=2` 的记录（节假日、加班日不计入明细）
2. **不展示当天**：明细表格中排除当前日期的记录
3. **统计规则**：
   - 已工作天数：不包含今天，仅统计工作日（假期flag=0）
   - 已累计工时：不包含今天的工时总和
   - 剩余工作日：本月范围内，包含今天及之后的工作日
4. **本月已结束**：若剩余工作日为 0，"剩余工作日预测"部分显示"本月已结束"

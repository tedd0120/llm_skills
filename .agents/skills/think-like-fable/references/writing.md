# 写作文档（writing）

> **何时在这里**：产出**给人读**的文字——文档、README、文章、报告、邮件、说明。
> 区分线：**当面把某概念讲懂**（互动、因人而异）→ `explanation.md`；**给定一份源**去摘要/改写/翻译 → `transformation.md`；要**生成点子/取名** → `ideation.md`；产出的是代码而非文字 → 回相应的构建 play。

## 崩点

**为读者写，不为自己写。** 头号失败是**作者视角的信息倾倒**——把你脑子里的一切按你理解的顺序倒出来，而不是按读者需要的顺序、给他需要的部分。清晰不来自堆砌，而来自**结构**与**删减**。第二杀手是**舍不得删**：初稿总是太长，而每一句"删了也不改变意思"的话都在稀释信号、消耗读者的注意力预算。

## 框架（重心：框定读者 + 收尾删减）

- **框定** — 明确**读者是谁**、他们**已知什么**、读完要能**做什么**（目的）。这决定一切内容取舍。
  - 关键问题：这是给谁看的？他们的背景？读完的具体行动是什么（照做/决策/理解）？
  - · 判据：说得清"给谁看、他看完能干什么"。
- **勘察** — 收集素材与事实，确认准确性（写错比啰嗦更伤信任）。
  - · 判据：要用到的事实都已核实。
- **谋划** — 先搭**结构/大纲**（结论先行 BLUF，或"问题→解决"，或步骤流）；一个层级一个主旨，先定骨架再填肉。
- **执行** — 按大纲起草；**一段一意**；**具体优于抽象**（用例子、数字、场景，而非形容词堆砌）。
- **验证** — **站在目标读者视角重读**：他能照着做/看懂吗？有没有用到他没有的前提？事实准不准？有无歧义？
  - · 判据：一个符合画像的读者能凭此达成目的。
- **收尾** — **无情删减**：删掉每一句"删了也不改变意思"的话（no-op）；术语统一；排版**可扫读**（标题、列表、加粗、代码块）。

## 关键手法

- **结论先行（BLUF, bottom line up front）**：把读者最想要的放最前；别让他翻到最后才看到重点，多数人根本翻不到。
- **一段一个想法**：一段只讲一件事；长段落是"没想清结构"的信号，拆开。
- **具体代替形容词**："快"不如"200ms 内返回"；"很多"不如"约 1 万条"；"安全"不如说清防住了什么。
- **可扫读排版**：多数人是扫不是读——用信息化的标题、短列表、加粗关键处，让扫读者也能抓到主干。
- **读者已知的不写，读者要做的写清**：砍掉他不需要的背景铺垫，补足他缺的关键步骤——这是"为读者写"的具体动作。
- **写完先砍 20%**：初稿几乎总能删掉五分之一而更好读；对每句做 no-op 测试——删了意思变吗？不变就删。

## 反模式（含识别信号）

- ❌ 作者视角信息倾倒 — _信号：你按"自己怎么想到的"顺序写、把知道的都塞进去_ → ✅ 按读者需要裁剪与排序
- ❌ 先埋头写、无结构 — _信号：你没列大纲就开始成段写_ → ✅ 先大纲后落笔
- ❌ 抽象空泛的形容 — _信号：满篇"高效、强大、灵活"却没有一个例子/数字_ → ✅ 具体例子/数字
- ❌ 舍不得删、越写越长 — _信号：你在往里加，从不往外删_ → ✅ 删掉每句 no-op
- ❌ 大段密文无法扫读 — _信号：整屏没有标题/列表/加粗_ → ✅ 分层排版

## 走一遍（示例）

> 任务：给一个内部 API 写接入文档（README）。
> **框定**：读者=第一次接入的其他团队开发者，已知 HTTP/JSON，不知你的业务；目的=读完能在 10 分钟内成功发出第一个请求。
> **勘察**：核实真实的 base URL、认证方式、一个能跑通的示例请求与响应、常见错误码。
> **谋划**：结论先行的结构——① 快速开始（一个 curl 就能跑通的最小示例）② 认证 ③ 端点列表 ④ 错误码 ⑤ 限流。最想要的"怎么发第一个请求"放最前。
> **执行**：每节一意；用**真实可复制的 curl 例子**和真实响应体，而非"发送一个请求即可"这种抽象描述；参数用表格。
> **验证**：站在"第一次接入者"视角照着走一遍——认证步骤够不够、示例能不能直接复制跑通、有没有用到只有内部人才懂的黑话。发现漏了"如何申请 token"，补上。
> **收尾**：砍掉一段自我介绍式的背景（读者不需要）；术语统一（"接口/端点"择一）；加小标题与列表让它可扫读。

## 完成的定义

- [ ] 目标读者能凭此完成预期目的
- [ ] 结构清晰、可扫读（结论先行、分层排版）
- [ ] 事实准确、术语统一、无歧义
- [ ] 无冗余：每句都 load-bearing，no-op 已删
- [ ] 未使用目标读者不具备的前提知识

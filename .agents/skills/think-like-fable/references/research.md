# 开放式调研（research）

> **何时在这里**：回答一个**开放世界**的问题，答案在你脑子和当前代码库之外——需要检索、查资料、比较、综合。"这东西怎么样""业界怎么做""XX 是什么来头""深度研究一下"。
> 区分线：搞懂自己的代码 → `comprehension.md`；分析手头的数据集 → `data-analysis.md`；要在候选中做选择并给推荐 → `decision.md`（调研常是它的上游）。

## 崩点

**开放世界里没有一个来源是天然可信的。** 两个杀手：**单一来源当真理**（一篇博客、一个论坛回答就下结论）；以及**把检索摘要当结论**、不回到原始出处、不做**三角验证**。信息会过时、会以讹传讹、会带立场、会是营销。调研的手艺不是"搜到"，而是**三角验证**（关键事实多源交叉）与**诚实标注置信度**。还有一层隐性风险：确认偏误——你只会搜到支持你预设的那些。

## 框架（重心：验证三角 + 收尾综合）

- **框定** — 把问题拆成**可回答的子问题**；明确"什么算够好的答案"与所需**置信度**（是随手一问，还是要下重注的决策依据？）。
  - · 判据：有一组具体子问题，而非一个笼统大问题。
- **勘察** — 针对每个子问题广泛采集**多个来源**；区分一手/二手、权威/传闻、事实/观点；随手记**出处与日期**。
  - · 判据：每个关键子问题都有多个来源在手。
- **谋划** — 规划验证策略：关键事实用 **≥2 个独立可信来源三角验证**；矛盾处标记待深挖；主动安排去找**反方证据**。
- **执行** — 逐子问题收集 → 交叉核对；跟踪矛盾与空白；对每条重要断言问"这来源可信吗、多久前的、有没有利益立场"。
- **验证** — 每个关键结论有多源支撑；**标注置信度**（高/中/低）；诚实呈现未知与反证，不藏矛盾。
  - · 判据：关键论断都能列出支撑来源与置信度，反方证据已被主动查过。
- **收尾** — 结构化综合：**结论先行** + 关键证据 + 出处 + 置信度 + 未决问题。

## 关键手法

- **来源分层**：官方文档/原始论文/一手数据 > 权威二手（知名媒体、成熟社区共识） > 无出处的"大家都说"。优先级越高越可采信。
- **查时间戳**：技术与时事类信息极易过时；发布/更新日期是硬指标，"三年前的最佳实践"可能已被推翻。
- **三角验证**：同一个数字/断言，两三个**互相独立**的来源对得上，才敢用；注意别把互相抄袭的来源当成"多个"。
- **主动证伪**：专门搜"X 的问题/缺点/反对意见/失败案例"，对抗确认偏误——只找支持证据的调研是不可信的。
- **区分事实与观点**：把"实测数据/官方声明"和"某人认为"分栏记，综合时别把观点当事实引。
- **对都市传说警惕**："人人都说但找不到原始出处"的论断，先存疑再求证。

## 反模式（含识别信号）

- ❌ 单一来源就下结论 — _信号：你的关键论断只挂着一个链接_ → ✅ 关键事实三角验证
- ❌ 把搜索摘要/二手转述当事实 — _信号：你引用的是"某篇总结说"，没看原始来源_ → ✅ 回到原始出处核对
- ❌ 只找支持预设的证据 — _信号：你没搜过任何反方观点_ → ✅ 主动找反证
- ❌ 隐藏不确定、把存疑说成确定 — _信号：全篇都是肯定语气，没有置信度标注_ → ✅ 显式标注置信度与未知
- ❌ 忽略信息时效 — _信号：你没留意来源日期_ → ✅ 核对发布时间

## 走一遍（示例）

> 问题："2026 年用 Rust 做后端 Web 服务成熟吗？主流选型是什么？"
> **框定**：拆子问题——(a) 生态成熟度（框架、ORM、异步运行时是否稳定），(b) 主流框架有哪些、各自定位，(c) 相比 Go/Node 的取舍，(d) 真实生产案例。用途=给一个技术选型决策做输入，置信度要求较高。
> **勘察**：每个子问题采多源——官方/框架文档、近一年的基准与社区调查、公司工程博客的一手实践、也搜"Rust 后端踩坑/劝退"取反方。
> **谋划**：框架流行度这类事实用"官方 star/下载 + 社区调查 + 招聘需求"三角；矛盾（有人说异步生态碎片化）标记深挖。
> **执行**：逐条核对；发现"某框架已停止维护"的传言 → 回到其 repo 看最近提交证伪/证实；主动读"劝退"帖了解真实痛点。
> **验证**：主流框架结论有三个独立来源支撑（高置信）；"异步生态"评价存在分歧 → 标中置信并呈现两方；标注"我未找到大规模中文业务的公开案例"这一未知。
> **收尾**：结论先行给选型建议，附证据、出处、置信度，以及"若你的团队没有 Rust 经验，学习曲线是最大未决风险"。

## 完成的定义

- [ ] 置信度与已知未知已显式标注
- [ ] 矛盾/反方证据已主动查找并呈现，而非选择性隐藏
- [ ] 来源时效已核对
- [ ] 综合结论直接回答了最初的问题（结论先行）
